# 珠海长隆飞船酒店两天一夜亲子行程

2026年8月1日—8月2日｜两大两小｜深圳福田景田自驾

这份页面按“现场拿手机直接照着执行”整理。核心策略是：

  • 8月1日约 08:30 从景田出发，第一天下午以一楼展馆和重点表演为主；
  • 8月1日晚外出吃饭后回飞船酒店游泳；
  • 8月2日早餐后退房寄存，约 09:00 提前入园；
  • 8月2日 11:00—12:00 跟拍，下午看巡游和虎鲸大秀；
  • 普通正餐按 人均约60—80元，上限100元 控制；
  • 8月2日晚根据孩子体力决定吃完再走，或直接返深。
酒店
横琴长隆飞船酒店
8月1日入住，8月2日退房
门票
飞船乐园两日无限次入园
住房套票住客可按酒店通知提前入园
摄影
8月2日约11:00跟拍1小时
10:20后停止激烈项目，整理服装
游泳
8月1日晚酒店无边际泳池
带4套泳衣、4顶泳帽；雷雨可能关闭
整体行程游玩路线节目表吃饭选择携带清单备用方案长图版

**重要说明：**节目时间根据出行前可查到的暑期节目表整理。8月1日、2日当天可能临时调整，入园后第一件事是查看长隆APP和现场电子屏。项目身高要求以入口现场量身和安全规则为准。

# 整体行程规划

# 8月1日：景田 → 飞船酒店 → 乐园 → 中央汇晚餐 → 游泳 → 房间

时间地点/移动具体安排执行重点
07:30—08:15景田家中早餐、洗漱、整理行李孩子吃饱并上厕所
08:15—08:30家中/停车位装车、证件复核乐园包、泳池袋、行李箱分开
08:30—08:45景田 → 飞船酒店正式出发推荐08:30，最晚不超过09:00
10:50—11:30飞船酒店停车场预计抵达以高德实时路况为准
11:00—11:40酒店前台登记入住、车牌授权、门票绑定、寄存行李房间没准备好也可先入园
11:40—12:25酒店食集或园内餐厅午餐按办完手续时间选择
12:30—17:55飞船乐园第一天游玩路线一楼展馆＋虎鲸之约＋水之光秀
18:00—18:15乐园 → 酒店房间领取房卡、放东西、上厕所稍作休息
18:15—18:30酒店 → 横琴中央汇自驾外出优先中央汇，餐厅选择更稳定
18:30—19:30中央汇晚餐四人控制约260—340元
19:30—19:50中央汇 → 酒店返回酒店确认泳池是否正常开放
19:50—20:00房间换泳衣、泳帽饭后不要立刻剧烈游泳
20:00—20:45酒店泳池游泳以酒店现场开放时间为准
20:45—21:40泳池 → 房间洗澡、吹头发、处理湿衣服湿衣物独立密封
21:40—22:00房间准备第二天跟拍服装、充电孩子尽量22:00前睡
22:00酒店房间第一天结束休息

第一天午餐快速判断

  • 11:20前办完手续：酒店1楼食集；
  • 11:20—11:40：看食集和乐园入口排队，哪边快去哪边；
  • 11:40以后：直接进园，在引力面馆或飞船餐厅吃。

# 8月2日：早餐 → 退房寄存 → 提前入园 → 跟拍 → 游玩 → 返深

时间地点/移动具体安排执行重点
07:10酒店房间起床、洗漱直接穿跟拍服装
07:30—08:15早餐餐厅使用套餐内早餐主食、鸡蛋、牛奶优先
08:15—08:40早餐厅 → 房间收拾全部行李湿泳衣独立密封
08:40—08:55前台/礼宾部退房、寄存行李不要等拍完再退房
09:00酒店住客通道提前入园先查当天提前开放项目
09:00—10:15乐园二楼玩热门项目需要时两位家长分组
10:15—10:35洗手间上厕所、擦汗、整理衣服之后不再玩水或激烈项目
10:35—10:50摄影集合点联系摄影师确认路线和入园情况
11:00—12:00乐园内一小时跟拍不安排完整换装
12:05—12:50园内餐厅午餐引力面馆或飞船餐厅优先
12:50—17:10飞船乐园下午游玩和表演小丑秀、巡游、虎鲸大秀
17:10—17:30乐园 → 酒店礼宾部取寄存行李、上厕所清点证件和随身物品
17:30以后横琴/返深途中晚餐三选一视孩子体力决定
18:30—19:00横琴 → 景田开始返程吃完再走则更晚
20:00左右中山段必要时休息10分钟司机和孩子都休息
21:00—21:45景田家中整个行程结束到家先处理湿衣物

# 飞船乐园游玩路线

# 第一天：一楼动物展馆＋核心表演

时间区域安排备注
12:30—12:50宇宙世界入口主题区、适应环境、简单拍照不在入口停留过久
12:50—13:15长江江豚馆看江豚和场馆展示顺路游览
13:20海牛馆美人鱼梦幻秀建议13:10到
13:35—14:15珊瑚馆、鲨鱼馆看珊瑚、鱼群、鲨鱼拍照区域

# 两个孩子的分组原则

  • 哥哥约121cm，弟弟约102cm，部分项目不能一起参加；
  • 项目入口的现场量身和安全规则优先；
  • 弟弟身高不足时，一位家长带哥哥排项目，另一位带弟弟玩低龄项目或看展；
  • 普通项目预计排队超过30分钟时，只保留孩子特别想玩的；
  • 两个孩子明显疲劳时，直接取消机动项目，转看展馆或表演。
